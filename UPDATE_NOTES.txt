InstaCard Editorial v3 업데이트

1. 자동 콘텐츠 유형 판단
- 빠른 정보형 3~6장
- 감성 에세이형 8~12장, 최대 13장
- 리스트·자기계발형 6~12장

2. 매거진형 레이아웃 5종
- 풀사진 표지
- 상단 글 + 하단 사진
- 리스트 + 하단 사진
- 어두운 사진 인용문
- 흰 배경 텍스트

3. 편집 기능
- 카드별 레이아웃 변경
- 제목·본문·목록·강조 구절 수정
- 리스트 시작 번호 수정
- 계정명 수정 및 저장

4. 이미지 기능
- 절약형 기본값: 표지만 AI 생성
- 모든 카드 AI 생성
- Pexels 무료 사진
- 직접 사진 업로드
- 카드별 사진 제거 및 교체

5. 출력
- 1080×1350 PNG
- 전체 ZIP과 caption.txt
- 정보·이미지 출처 기록

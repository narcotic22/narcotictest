# InstaCard Editorial v3

개인 비밀번호로 접속하는 인스타그램 카드뉴스 제작 웹앱입니다. 빠른 정보형뿐 아니라 감성 에세이형과 리스트형 롱폼 카드뉴스를 자동 구성합니다.

## 이번 버전 핵심 기능

- `자동 판단`을 기본값으로 사용
- 빠른 정보형: 3~6장
- 감성 에세이형: 8~12장, 필요한 경우 최대 13장
- 리스트·자기계발형: 6~12장
- 카드 장수와 레이아웃을 AI가 자동 결정
- 풀사진 표지
- 상단 흰 배경 + 하단 사진
- 리스트 + 하단 사진
- 어두운 사진 위 중앙 인용문
- 흰 배경 텍스트 카드
- 인용문 핵심 구절 포인트 색상 강조
- 카드별 레이아웃 수동 변경
- 카드별 AI 이미지·Pexels 사진·직접 사진 업로드
- 비용 절약형 이미지 설정: 표지만 AI 생성
- 계정명 저장
- 개별 PNG 및 전체 ZIP 다운로드

특정 인스타그램 계정의 콘텐츠를 복제하지 않고, 여백이 넓고 사진과 글의 호흡이 좋은 매거진 편집 원칙을 바탕으로 독자적인 템플릿을 사용합니다.

## 필요한 환경변수

```env
APP_PASSWORD=본인만아는비밀번호
SESSION_SECRET=32자이상의무작위문자열
OPENAI_API_KEY=발급받은키
OPENAI_TEXT_MODEL=gpt-5
OPENAI_IMAGE_MODEL=gpt-image-1
PEXELS_API_KEY=선택사항
```

- OpenAI 관련 환경변수는 이미 Vercel에 넣었다면 다시 입력할 필요가 없습니다.
- `PEXELS_API_KEY`가 없으면 무료 사진 버튼은 동작하지 않습니다.
- 기본 이미지 모드는 `절약형`이며 표지 한 장만 AI 이미지로 생성합니다.

## GitHub에 업데이트하는 방법

1. ZIP 압축을 풉니다.
2. 압축을 풀었을 때 보이는 `app`, `components`, `lib`, `package.json` 등의 파일과 폴더를 GitHub 저장소 최상단에 업로드합니다.
3. 기존 파일 교체를 승인하고 `Commit changes`를 누릅니다.
4. Vercel이 자동으로 새 버전을 배포합니다.
5. 배포 완료 후 웹앱에서 `Ctrl + Shift + R`로 강력 새로고침합니다.

## 권장 첫 테스트

- 콘텐츠 형식: 자동 판단
- 문체: 차분한 매거진형
- 이미지: 절약형
- 예시 주제: `외로워서 시작한 연애가 나를 더 외롭게 만들 때`
